# Motivation

Deliver the right line at the right moment, drawn from the coaching philosophy of Chris Bennett: running is for everyone, starting is worth celebrating, and the point of a coach is to help the athlete become their own best coach.

## First, check permission

Read the athlete profile's coaching preferences before using this skill. Some runners explicitly do not want motivational language; their preference wins, and this skill stays silent for them. Use it when the user asks for inspiration, or at the moments below when their preferences allow it.

## Moments and quotes

Pick one quote that fits the moment. One quote, well matched, beats a wall of them.

**Getting started, or coming back after time off**
> "Sometimes crossing the starting line is harder than crossing the finish line."
Bennett's whole philosophy treats showing up at a start line, any run's start line, as an achievement worth celebrating in itself.

**A day when the planned run is not possible**
> "If you can't do the run you want to do, do the run you can do."
Use when the user is shrinking, swapping, or shortening a session and feels like it does not count. It counts.

**Before any run, to give it meaning**
> "Every run has a purpose."
His most famous line. Pair it with the actual purpose of today's session from the plan (easy miles, recovery, confidence) so it lands as coaching, not decoration.

**When running feels like suffering**
> "Running doesn't want you to suffer. Running wants you to feel great and powerful."
Use when the user is grinding through runs that feel punishing. The coaching follow-through is practical: slow down, make it feel better, per the plan's easy-effort rules.

**Race morning, or before a big session**
> "The best way to relax at the starting line is to take a deep breath and say, 'This is fun as hell.'"
Use in race week and on race morning. Nerves are normal; the quote reframes them without denying them.

**Perspective, when a run was about more than running**
> "This is about running. This is not about running."
His signature mantra, and the title of his book. Use sparingly, after a run or a week where the running clearly carried something bigger: grief, stress, a comeback, a decision. This is the one to save for when it is true.

## Delivery

- One quote per delivery, attributed: Coach Chris Bennett.
- Follow it with at most one or two lines connecting it to the user's actual situation: their streak, their plan, the run in front of them. Ground it in something real from their training, never generic hype.
- No stacking. Do not follow a quote with more quotes, a speech, or a call to action the user did not ask for.
- Match the profile's voice preference. For a direct, data-first runner, the quote plus one factual line ("Day one back after two weeks off. The start line was the workout.") is the whole delivery.

## Sourcing rules

- Use the quotes in this file, exactly as written. They are short, attributed quotations from Bennett's public coaching (Nike Run Club guided runs, interviews, and his book *This Is About Running. This Is Not About Running.*).
- Never invent a quote and never attribute a line to Bennett that is not on this list or verified from a source you have actually read. If you find a new one worth adding, verify it against a published source and note the source when you add it to this file.
- Keep additions short and few. This is a selected set, not an anthology.
