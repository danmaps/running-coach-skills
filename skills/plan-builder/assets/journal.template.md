# Running Journal

Keep this file in the private working folder with the athlete profile and plan. The plan remains the source of truth for accepted targets and session status; the journal records context, subjective reports, patterns, and lessons that should inform future proposals.

The agent may draft objective fields from confirmed activity data. The athlete owns the subjective record and may edit or write freeform at any time. Leave unknown fields blank or mark them "not reported"; never infer them.
