# Weekly Check-In

Read and apply the [shared coaching rules](references/coaching-contract.md) before proceeding.


## Process

1. Read the profile, dated session ledger, observations, adjustments log, and journal entries for the review period when a journal is kept. Establish the review period in the athlete's timezone using the configured week start. Review the last completed calendar week by default; label a rolling seven-day or partial-week review explicitly.
2. Retrieve that period and the prior comparable period using the shared data rules. Deduplicate mirrored activities before totals. Report coverage and freshness; distinguish unknown sessions from skipped sessions and rest.
3. Match actual activities to dated sessions by saved IDs and local dates. Ask when matches are ambiguous. Keep unplanned runs visible and count each actual run only once. Use the accepted target in effect before the session, including logged changes.
4. Compare planned vs actual sessions, distance and/or duration, and long run. Do not invent planned mileage for duration-only sessions; show distance and duration separately. Where coverage is incomplete, label actuals as observed minimums and withhold unsupported completion percentages.
5. Look for recurring schedule problems, repeated overreach, recovery issues, and conflicts with strength training. Read plan observations and journal reports alongside numbers: repeated body notes, declining feel, poor sleep, heavy life context, and fueling failures can explain a gap or support an adjustment. Identify the journal evidence by date when it matters. Do not infer a training pattern from one outlier.
6. Offer no more than one or two reconciled adjustments if warranted. Never add catch-up volume. On acceptance, update the existing dated rows, weekly structure if needed, and adjustments log. Save factual summary observations by review-period key without another confirmation. Repeat runs must update that record rather than append duplicates.

## Output

- Exact review period and data coverage.
- Small planned vs actual table and prior-period comparison.
- One useful observation.
- Proposed adjustment, or confirmation that no change is warranted.

## Guardrails

Never shame missed work or add motivational filler. Missing data is not noncompliance. Symptoms override ordinary trend-based coaching; follow the shared rules.
