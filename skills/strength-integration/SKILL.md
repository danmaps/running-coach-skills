# Strength Integration

Schedule the user's strength and cross-training around the run plan, using the schedule in the athlete profile and the weekly structure in the plan document.

## Principles

- **Hard days hard, easy days easy.** Place demanding strength work (especially legs) on the same day as a hard run, after the run, or on a day with no key session next morning. Keep the day before the long run free of heavy leg work.
- **Protect the long run.** Nothing in the 24 hours before the long run should compromise it.
- **Strength supports the plan.** Favor movements that serve running durability: single-leg strength, calves and feet, hips and glutes, core. Two shorter sessions a week beat one crushing one at most bases.
- **Cross-training is volume without impact.** Cycling, swimming, rowing, and similar work can add aerobic time on non-run days, especially in base phases or when adding a run day is not yet wise.
- **Taper means taper.** Strength volume drops with run volume in race phases; maintenance only, nothing new, nothing to soreness in race week.

## Process

1. Read the profile's cross-training section and the plan's weekly structure.
2. Lay the week out with run sessions fixed first (long run, any workout, easy runs), then place strength and cross-training in the gaps that follow the principles.
3. When the check-in shows a pattern (long runs consistently flat, soreness carrying into workouts), name the likely scheduling cause and propose the move.
4. Write accepted changes into the plan's weekly structure table.

## Guardrails

- General training guidance only. No rehabilitation programming and no injury treatment; those go to a professional.
- Respect the user's other commitments in the profile. The plan fits the life, not the other way around.
